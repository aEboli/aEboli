# 发布实时 3D 主页

## Why

用户明确要求把已修正握把、脚踏和身体动作的鲸鱼娘骑行同步到 GitHub 主页，并确认真实时间变化。当前公开简介仍使用旧 SVG，完整网页仅在本地。

## What Changes

- 将最终 3D 动图作为简介横幅，点击进入 GitHub Pages。
- 保留 `site/` 中的源码、验证和许可证；构建至仓库根目录 `docs/`，使用 Pages 的 `main:/docs` 发布。
- 默认入口不携带预览时间参数，保持真实北京时间及自动昼夜更新。
- 发布后验证线上资源、真实时钟、暂停期间的昼夜更新和简介入口。

## Impact

仅修改 `aEboli/aEboli` 的首页横幅及本次 3D 页面相关内容。用户的“同步更新到我 GitHub 主页”已经确认发布范围；保留现有项目介绍。
