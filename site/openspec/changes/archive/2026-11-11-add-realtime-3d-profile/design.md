# 设计

沿用 Three.js 0.187.0 和已有模型，改用 PerspectiveCamera、物理材质、环境光照与实时投影。角色造型、自我介绍及顺时针骑行方向保留。复用腿部网格，避免每帧重建几何体。

时间逻辑与动画进度独立，显式使用 `Asia/Shanghai`。05:00–07:00 过渡到白天，16:00–19:30 过渡到夜晚；这是美术时间表，不计算天文日出。颜色、灯光和星空透明度连续变化，跨午夜一致。自动模式每秒重读真实时钟，恢复标签页时立即更新。查询参数只用于固定小时的截图验证。

交付网页包含全部模型和浏览器依赖，不依赖 CDN。鼠标及触屏可旋转视角，键盘可通过按钮复位和暂停。小屏纵向排版，并尊重减少动态效果设置。

发布集成需要用户查看本次预览后再继续：GitHub 简介使用横幅链接 GitHub Pages；独立网页承担真实时间和交互。此次不启用计划任务，不将自动循环 GIF 当成真实时钟。
