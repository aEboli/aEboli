# 实时昼夜 3D 鲸鱼娘主页

## Why

现有横幅使用平面感较强的卡通材质和固定背景，不能体现用户要求的立体效果，也不能跟随真实时间变化。用户已确认采用北京时间的真实昼夜。

## What Changes

- 保留鲸鱼娘、向前骑行和已确认的自我介绍，升级透视、材质、光照、阴影及立体海边道路。
- 使用 `Asia/Shanghai` 时间连续插值白天、晨昏和夜晚，打开页面和持续停留均更新；夜间出现星光、月光和车灯。
- 提供拖动旋转、复位、暂停和适配小屏的静态网页，可部署到 GitHub Pages。
- 交付可运行网页、昼夜效果图、源码及验证记录；本次预览未经审阅不替换已公开的 GitHub 横幅。

## Impact

仅修改 `whale-cyclist-three` 及本次生成的交付产物。GitHub README 不执行 JavaScript，因此实时 3D 在独立页面运行；README 可链接该页面，不能把 GIF 宣称为实时昼夜。

## Confirmation

用户请求“我要3D效果的，并且随着时间夜晚白天变化的”，并选择“按真实时间切换：跟随北京时间的白天、黄昏和夜晚”。此范围已由用户确认，直接实施并提供具体预览。
