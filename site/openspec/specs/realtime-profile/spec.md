# realtime-profile Specification

## Purpose
为 aEboli 提供带鲸鱼娘骑行角色和自我介绍的独立 3D 主页，按真实北京时间连续更新昼夜，支持拖动查看和暂停。

## Requirements

### Requirement: 立体鲸鱼娘骑行
页面 MUST 呈现可旋转的透视 3D 场景、受光材质及落地阴影，保留可爱的鲸鱼服装、二次元面部和向前骑行。

#### Scenario: 查看立体场景
- **WHEN** 用户打开页面并拖动场景
- **THEN** 摄像机角度改变，人物、自行车及道路产生真实透视和遮挡变化
- **AND** 脚踏与车轮沿向右骑行的方向同步旋转

### Requirement: 北京时间实时昼夜
页面 MUST 按 `Asia/Shanghai` 的真实时间更新光照，动画进度不得驱动昼夜切换。

#### Scenario: 昼夜效果
- **WHEN** 北京时间分别为 12:00、18:00 和 22:00
- **THEN** 页面分别呈现日光、黄昏和夜景
- **AND** 夜间车灯和星空可见且人物面部仍可辨识

#### Scenario: 页面持续打开
- **WHEN** 实际时间经过晨昏边界或者标签页从后台恢复
- **THEN** 页面自动重新读取真实时钟并更新场景，不需要刷新

#### Scenario: 不同设备时区
- **WHEN** 同一时刻的访问者设备分别处于上海和洛杉矶时区
- **THEN** 场景使用相同的北京时间和昼夜状态

### Requirement: 可访问的独立页面
页面 MUST 保留自我介绍，在桌面和手机均可操作，并提供暂停和复位。

#### Scenario: 减少动态效果
- **WHEN** 浏览器启用减少动态效果
- **THEN** 骑行动画默认暂停且真实昼夜时钟仍正常更新

#### Scenario: 静态部署
- **WHEN** 交付目录通过 HTTP 服务或 GitHub Pages 提供
- **THEN** 页面加载本地依赖并运行，无需任何密钥或后端服务

### Requirement: 协调的骑行姿态
骑行动画 MUST 使双手包握把套、肘部自然弯曲，并使躯干和肩胯随踩踏轻微移动，手脚接触约束保持成立。

#### Scenario: 整圈踩踏
- **WHEN** 角色完成一次踩踏循环
- **THEN** 双手始终固定在把套，双脚始终贴合踏板
- **AND** 肩胯随踩踏连续变化，手肘跟随身体弯曲，肢体长度稳定

#### Scenario: 循环与暂停
- **WHEN** 动画循环到开头或者用户暂停
- **THEN** 循环没有姿态跳变，暂停时整套身体动作保持静止
- **AND** 暂停不影响真实昼夜更新

### Requirement: GitHub 主页发布
GitHub 个人简介 MUST 展示最终的鲸鱼娘骑行动图，并链接到公开可访问的完整 3D 页面。公开入口 MUST 使用真实北京时间，不携带固定时刻或截图参数。

#### Scenario: 从简介访问实时场景
- **WHEN** 访问者点击简介横幅或“进入 3D 主页”
- **THEN** 打开同一 GitHub Pages 地址，页面的时区为 `Asia/Shanghai`，模式为 `live`
- **AND** 页面自动随时钟更新昼夜，暂停骑行不暂停真实时钟

#### Scenario: 发布与维护
- **WHEN** 维护者在 `site/` 执行 `npm ci`、`npm test`、`npm run build:pages` 并推送
- **THEN** `main` 的 `docs/` 目录包含完整静态页面、模型和依赖许可证，可由 GitHub Pages 发布
- **AND** 简介中的 GIF 仅作为动画预览，不声称其本身能读取真实时间
