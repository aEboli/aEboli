# 实时昼夜 3D 验证

验证日期：2026-11-11。环境：Windows、Microsoft Edge、Three.js 0.187.0。

## 已通过

- `npm test`：4 项时间逻辑测试全部通过，包括北京时间换算、日/昏/夜状态、晨昏连续插值和午夜边界。
- `npm run build`：生成可独立部署的 `dist/`，包含模型和 8 个实际引用的 Three.js 模块及许可证文件。
- `python tests/browser-check.py`：构建页面实际加载，JavaScript 控制台无错误。
- 用浏览器中的可控真实时钟从北京时间 12:00 推进到 18:00、22:00、23:59、00:00；定时更新自动生效，未调用手动刷新接口。
- 暂停骑行后动画进度保持不变，真实时钟和灯光仍更新；夜间前灯亮起。
- 设备时区分别为洛杉矶和上海时，同一 UTC 时刻均显示北京时间 12:00。
- 鼠标拖动可改变真实摄像机位置，紧接着复位可精确恢复默认角度。
- 320、390、768、1100 像素宽度无横向溢出，文案及控制按钮在视口内；查看了手机与桌面截图。
- 减少动态效果开启时默认暂停。
- 预热不同可见姿态后，连续两轮逐帧渲染的 GPU 几何体数量稳定；不再每帧创建腿部几何体。
- 脚踏和车轮沿向右骑行的方向旋转，道路标线向左移动。
- 踏板修复先执行 `python tests/pedal-check.py`，原版本因缺少完整左右踏板而失败；修复后整圈 12 个姿态通过：脚底贴合踏面、两踏板相差半圈、踏板保持水平、踏板轴与踏板相连。已检查四个象限的近景截图。
- 握把与身体动作先执行 `python tests/riding-pose-check.py`，原版本因缺少完整握把约束而失败；修复后 37 个姿态通过：手部锚点固定在把套、上臂和前臂长度稳定、躯干转动和肩胯位移存在、循环首尾一致。
- 使用原始模型的手部皮肤与手指关节，弯曲指节，并为把套留出掌心空间；从顶部和底部查看近景，修复了手指与把套的明显穿插。袖子通过肩—肘—腕联动连接，保持握把位置。
- 身体绕骨盆轻微前倾和左右转移重心，头部反向补偿保持稳定；发梢、帽鳍和尾鳍带滞后。固定镜头导出便于区分身体动作与摄像机运动。
- 已人工检查白天、黄昏、夜晚的材质、阴影、文字留白和人物清晰度。
- 导出的昼夜效果动画均为 135 帧、25fps、5400 毫秒无限循环；导出时控制台无错误。
